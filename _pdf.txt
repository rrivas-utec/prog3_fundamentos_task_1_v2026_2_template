Ejercicio 1 (Básico · 12 min): IntStack y copia profunda
El código base ya incluye push, pop y top. Complete constructor, destructor y constructor de copia. Una copia
debe tener un arreglo propio.

  class IntStack {
     int* data_;
    std::size_t size_;
    std::size_t capacity_;
   public:
     explicit IntStack(std::size_t capacity = 8);
     IntStack(const IntStack& other);
     ~IntStack();
     void push(int value);
     void pop();
     int top() const;
     bool empty() const; // given
  };


Caso de prueba:

  IntStack source(4);
  source.push(10);
  source.push(20);
  IntStack copy(source);
  copy.pop();
  copy.push(99);
  assert(source.top() == 20);
  assert(copy.top() == 99);
